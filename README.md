# Contact Book API

A RESTful API built with **FastAPI** for managing contacts. This application allows users to create, read, update, and delete contact information, with built-in authentication and admin capabilities.

## Features

- **Contact Management**: Create, view, update, and delete contacts.
- **Authentication**: Secure endpoints using JWT authentication.
- **Admin Panel**: Administrative privileges for user management.
- **Database Integration**: Built with SQLAlchemy ORM (configured for PostgreSQL).

## Project Structure

```
ContactBookAPI/
├── routers/          # API route handlers (contacts, auth, admin)
├── database.py       # Database connection and session management
├── main.py           # Application entry point
├── model.py          # Database models
└── .env              # Environment configurations (not committed)
```

## Getting Started

### Prerequisites

- Python 3.8+
- PostgreSQL (or adjust `database.py` for SQLite)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd ContactBookAPI
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    python -m venv venv
    # Windows
    .\venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies:**
    ```bash
    pip install fastapi uvicorn sqlalchemy psycopg2-binary python-dotenv pydantic passlib[bcrypt] python-jose[cryptography] multipart
    # Note: Create a requirements.txt if not utilizing one currently
    ```

4.  **Configure Environment Variables:**
    Create a `.env` file in the root directory and add your database configuration:
    ```env
    DATABASE_URL=postgresql://user:password@localhost:5432/contact_book_database
    SECRET_KEY=your_secret_key
    ALGORITHM=HS256
    ```

### Running the Application

Start the development server with Uvicorn:

```bash
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.

### API Documentation

Interactive API documentation is automatically generated by FastAPI:

- **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
